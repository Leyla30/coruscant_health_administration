# Welcome to Coruscant Health Administration
***

## Task
The goal of this project was to create a simple healthcare management system that allows doctors and patients to use the same platform and manage medical information in one place.

## Description
To solve this problem, we developed a Django web application with separate functionality for patients and doctors. The project includes user registration, profile management, dashboards, and medical record management. Patients and doctors can be stored in the system, while medical information such as health readings, reports, service orders, and department results can be created and managed through the application.

The project is organized into two Django applications. The first application is responsible for user accounts, registration, and profiles. The second application handles medical data and related operations. Django models, forms, views, templates, and migrations were used to implement the required functionality.

## Installation
Install Django:pip install django
Apply migrations:python manage.py migrate
Run the server:python manage.py runserver 0.0.0.0:8000

## Usage
After starting the server, open the application. Users can register as patients or doctors, access their profiles, and manage medical information through the available pages.

```
./my_project argument1 argument2
```
